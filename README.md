# OM-Xmass

Festive save-the-date page for Traditional OM-Xass lunch.

Friday 27 November 2026, 12:30–16:30 Europe/Copenhagen (11:30–15:30 UTC).

Live site: https://petermalmkjaer.github.io/OM-Xmass/

Calendar links: Microsoft 365, Outlook.com, Google Calendar, and an interoperable ICS download. Adding the event is not registration. Imported calendar events do not automatically receive later updates.

The PNG and SVG QR codes point to the permanent landing page. Keep this URL unchanged when updating the page.

GitHub Pages serves the root of main. No build tools or external assets are required.
